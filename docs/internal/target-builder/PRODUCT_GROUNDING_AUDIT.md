# Story Builder Target Builder — Product Grounding Audit

## Ground truth checked against current Story Builder main

The replacement builder is now restricted to capabilities present in the current product or clearly labeled educator-facing guidance.

### Verified current product

- Seven Story Goals:
  - Story Organization
  - Connections & Cohesion
  - Cause & Effect
  - Sentence Formulation
  - Elaboration
  - Perspective & Internal State
  - Vocabulary Precision
- `Observe First · Choose After First Tell` is workflow/default, not a student objective.
- Actual in-app phases:
  **First Tell → Work on Target → Tell Again**
- Story Goal selection is a separate educator control.
- Whole → Part → Whole is explicit.
- First Tell occurs before the Planner/targeted support when using the teaching cycle.
- Work on Target opens the Planner and targets one selected breakdown.
- Current progressive educator support sequence:
  **Look here → Think about it → A clue → Words to try → Sentence start**
- Student attempts first; only the next support step is revealed.
- Retry returns the student to the same language demand.
- Repaired language is reconnected to the story.
- During Tell Again, targeted help stays closed.
- Planner reference during Tell Again is educator-controlled and may be hidden for an independent whole-story tell.
- Instructional support intentionally does not score performance.
- Current product explicitly distinguishes access support from support for the instructional target.
- Student Mode supports are selected, target-specific student-facing supports derived from the educator instructional content.

## Grade-band truth

The current Story Builder runtime does **not** contain Grades 2–3 / 4–5 / 6–8 prompt engines.

The builder's grade bands are **educator-facing developmental calibration only**:
- objective wording;
- developmental expectation;
- interpretation of independence.

They do not change the actual Story Builder prompt/support sequence.

## Features intentionally removed from generated claims because they are not current Story Builder modules

- systematic multi-step/competing/counterfactual causal reasoning;
- systematic sentence combining / advanced syntax hierarchy;
- dialogue/pacing/reflection/literary craft;
- two-character perspective comparison / false belief / perspective-change curriculum;
- connotation/register/tone / broad vocabulary curriculum.
